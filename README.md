# Peinture Mirabel

Site vitrine d'une équipe de peintres en bâtiment spécialisés en post-construction à Mirabel, Québec.

## Stack
HTML5 + CSS3 + JavaScript vanilla. Aucune dépendance, aucun framework.

## Structure
```
peinturemirabel/
├── index.html
├── css/styles.css
├── js/main.js
├── img/
├── favicon.svg
├── site.webmanifest
├── vercel.json
├── robots.txt
└── sitemap.xml
```

## Déploiement (Vercel)
1. Importer ce dossier comme nouveau projet sur Vercel.
2. Aucune commande de build requise (site statique).
3. Pointer le domaine `peinturemirabel.ca` vers Vercel.
